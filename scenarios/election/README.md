# Election Scenario

Simulates voter behavior and opinion formation in a local political election. Two candidates campaign with competing platforms while voters form opinions through discussions, news coverage, and campaign events. A news outlet provides coverage that influences the conversation.

## Engine

**Sequential** (default) — Agents take turns acting. The game master injects campaign events (town halls, debates, rallies, endorsements) between agent actions.

## Agent Types

### Voters (`VoterAgent`)

Citizens who form opinions and decide how to vote. Each voter has a persona, communication style, and initial political lean that can shift during the simulation.

| Voter | Background | Style | Initial Lean |
|-------|-----------|-------|-------------|
| **Maria Chen** | Small business owner, worried about taxes/regulation | Pragmatic | Slight conservative |
| **James Wright** | Retired teacher, values education funding | Thoughtful | Progressive |
| **Sarah Miller** | Young tech professional, cares about climate/housing | Analytical | Undecided |
| **Robert Johnson** | Factory worker, concerned about job security | Direct | Slight conservative |
| **Emily Davis** | Healthcare worker, prioritizes public health | Empathetic | Slight progressive |

**Components:**

1. **Memory** — Associative memory bank
2. **Instructions** — Agent identity
3. **Persona** — Background and concerns
4. **Disposition** — Political lean + communication style description
5. **Observations** — Last 30 events
6. **Goal** — Voting objective
7. **SituationPerception** — LLM: "What is {name}'s current understanding of the election?"
8. **VoteIntention** — LLM: "How is {name} currently leaning?" (retrieves 15 memories)
9. **BestAction** — LLM: "What should {name} do or say next?"

**Communication styles:** pragmatic, thoughtful, analytical, direct, empathetic

**Political leans:** conservative, slight_conservative, undecided, slight_progressive, progressive

### Candidates (`CandidateAgent`)

Politicians campaigning for office with policy platforms and campaign strategies.

| Candidate | Partisan Type | Campaign Style | Key Policies |
|-----------|--------------|----------------|-------------|
| **Thomas Morrison** | Conservative | Traditional | Lower taxes, reduce spending, traditional values, law enforcement |
| **Elena Rodriguez** | Progressive | Grassroots | Education/healthcare investment, environment, affordable housing, safety net |

**Components:**

1. **Memory** — Associative memory bank
2. **Instructions** — Agent identity
3. **Platform** — Partisan description + policy proposals
4. **CampaignStyle** — How they campaign (traditional, grassroots, populist, technocratic)
5. **Observations** — Last 30 campaign events
6. **Goal** — Win the election
7. **SituationPerception** — LLM: "What is the current state of {name}'s campaign?"
8. **VoterAnalysis** — LLM: "What are voters concerned about?" (retrieves 10 memories)
9. **BestAction** — LLM: "What is the best campaign action?"

### News (`NewsAgent`)

A news outlet providing election coverage with prepared headlines.

| Agent | Style | Headlines |
|-------|-------|----------|
| **Local News** | Local journalism | 5 prepared headlines on economy, environment, healthcare, small business, education |

**Components:**

1. **Memory** — Associative memory bank
2. **Instructions** — Agent identity
3. **Approach** — Editorial style (local_journalism, investigative, balanced, breaking_news)
4. **Headlines** — Pre-written headlines ready to report
5. **Observations** — Last 40 developments
6. **Goal** — Fair and informative coverage
7. **SituationPerception** — LLM: "What is the current state of the election race?"
8. **StoryAnalysis** — LLM: "What are the most newsworthy developments?" (retrieves 15 memories)
9. **BestAction** — LLM: "What should {name} report on next?"

## Game Master

`ElectionGameMaster` manages the simulation with election rules, candidate tracking, and campaign event injection. Uses Concordia's `SwitchAct` component for GM actions.

**Dynamic events** generated by `scenarios/election/events.py`:
- Campaign events (town halls, debates, rallies)
- News events and polls
- Voter interactions and endorsements
- Community events

**Knowledge builder** (`scenarios/election/knowledge.py`) injects role-specific background knowledge at simulation start.

## Configuration Options

In `config/scenario/election.yaml`:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `agents.entities[*].params.initial_lean` | Per voter | Starting political leaning |
| `agents.entities[*].params.communication_style` | Per voter | How they discuss politics |
| `agents.entities[*].params.partisan_type` | Per candidate | conservative / progressive / moderate |
| `agents.entities[*].params.campaign_style` | Per candidate | traditional / grassroots / populist / technocratic |
| `agents.entities[*].params.outlet_style` | Per news agent | local_journalism / investigative / balanced / breaking_news |
| `game_master.params.campaign_events` | town_hall, debate, rally, endorsement | Event types injected |
